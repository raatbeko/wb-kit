# Дополнение «Сводка, план закупки, ниша» — как добавить в установленный wb-kit

Это инструкция для Claude, который работает в папке wb-kit у продавца. Человек дал тебе архив ветки `panel` и просит добавить новые возможности. В этом архиве два дополнения: панель (`ДОПОЛНЕНИЕ-ПАНЕЛЬ.md`) и это — сводка, план закупки, ниша. Делай по шагам и рассказывай простыми словами, что происходит.

## Что даёт дополнение

- `/digest` — **утренняя сводка** без Claude: заказы вчера, что закончилось и закончится, что просело, отзывы без ответа, дела на сегодня. Блок «Сегодня» вверху панели и сообщение в Telegram. По расписанию через Планировщик заданий Windows.
- **Telegram** — свой бот продавца: `npm run telegram` сам находит ID чата.
- `/plan` — **план закупки**: сколько штук каждого товара завезти по месяцам, с сезоном, выкупом, остатками WB и своими, сроком поставки; «заказать до», локомотивы, лишний остаток. HTML с фото и Excel.
- `/niche` — **ниша**: выдача WB «по популярности» и «новинки», сегменты, новинки в топе, бренды, вердикт «стоит ли заходить», сетка фото. Без запросов — ниша самого продавца.
- В панели появляются вкладки «Закупка» и «Ниша», срочное из плана попадает в консоль логиста.

Новых зависимостей нет: `npm install` не нужен.

## 1. Сначала панель

Сводка, план и ниша встраиваются в панель магазина (`/panel`), поэтому порядок такой:

- Нет файла `panel/build.ts` — сначала поставь панель по `ДОПОЛНЕНИЕ-ПАНЕЛЬ.md` из этого же архива, потом вернись сюда. Проще всего сделать оба шага разом: файлы обоих дополнений лежат в архиве в готовом виде.
- Панель уже стоит — переходи к шагу 2.

Если в папке есть `.git`: `git log --oneline -1`. На коммите `985ff3c` (основная версия от 21.11.2026) или `5bbc05a` (уже с панелью) файлы можно просто заменять. На другом коммите сравни файлы из списка «Изменены» с архивом. Чужие правки не затирай — переноси изменения вручную.

## 2. Скопировать файлы

Распакуй архив во временную папку, не в wb-kit, и скопируй оттуда.

**Новые — скопировать как есть:**

- `digest/` — сводка (`digest.ts`, `digest.test.ts`)
- `plan/` — план закупки (`plan.ts`, `render.ts`, `plan.test.ts`)
- `niche/` — ниша (`niche.ts`, `render.ts`, `demo.ts`, `niche.test.ts`)
- `scripts/digest.ts`, `scripts/digest.cmd`, `scripts/plan.ts`, `scripts/niche.ts`, `scripts/telegram.ts`, `scripts/telegram.test.ts`
- `.claude/commands/digest.md`, `plan.md`, `niche.md`
- `ДОПОЛНЕНИЕ-СВОДКА-ПЛАН-НИША.md` — эта инструкция

**Изменены — заменить или перенести правки:**

| Файл | Что добавлено |
|---|---|
| `package.json` | скрипты `digest`, `plan`, `niche`, `telegram` |
| `tsconfig.json`, `vitest.config.ts` | папки `digest/`, `plan/`, `niche/` |
| `.env.example` | в конце пустое поле `TELEGRAM_CHAT_ID=` с комментарием |
| `scripts/set-key.ts` | ключ `TELEGRAM_CHAT_ID`; повторы строки ключа в `.env` убираются |
| `scripts/check.ts` | строка «Сводка в Telegram», возможности `/plan` и сводки |
| `panel/build.ts`, `scripts/panel.ts` | блок «Сегодня», вкладки «Закупка» и «Ниша», находки плана и ниши |
| `audit/demo.ts` | демо-история старше 90 дней с сезоном (для `/plan`), свой склад у подушки |
| `competitors/cdn.ts` | `photoUrl` и `CardFetcher.basket` — фото товаров с публичного CDN WB |
| `.claude/agents/*.md` | роли читают свежие `plan-*`, `niche-*` и сводку; логист и разведчик — где брать план и нишу |
| `.claude/commands/wb.md` | строки `/digest`, `/plan`, `/niche` в меню |
| `CLAUDE.md`, `README.md` | описание команд, Telegram, таблица ключей |

**Не трогать:** `.env`, `data/`, `reports/` — это данные человека, в архиве их нет. Ключи в `.env` руками не вписывай: токен бота человек присылает сам, сохраняй его через `npm run set-key`.

## 3. Разрешить команды без лишних вопросов

В `.claude/settings.json`, в список `permissions.allow`, рядом с другими `npm run`:

```json
"Bash(npm run digest:*)",
"Bash(npm run plan:*)",
"Bash(npm run niche:*)",
"Bash(npm run telegram:*)",
```

Покажи человеку эту правку и спроси разрешения. Если он против — Claude Code просто будет спрашивать перед каждой командой.

## 4. Проверить

1. `npm test` — все тесты должны пройти.
2. Демо — без ключа:
   - `npm run digest -- --demo --no-send`
   - `npm run plan -- --demo`
   - `npm run niche -- --demo`
   - `npm run panel -- --demo` — в панели блок «Сегодня» и вкладки «Закупка» и «Ниша».
3. С ключом WB — `npm run digest`. Если человек хочет сводку каждое утро — `npm run digest -- --schedule 08:00`.

## 5. Рассказать человеку

Коротко:

- «Теперь каждое утро может приходить сводка — в панель и в Telegram, без Claude. Включить: `/digest расписание 08:00`, Telegram — `/digest telegram`.»
- «`/plan` посчитает, что и сколько заказать на 3 месяца с учётом сезона.»
- «`/niche` покажет лидеров и новинки в вашей нише с фото и скажет, стоит ли заходить.»

Попробовать без ключа: `/plan демо`, `/niche демо`. Перезапуск Claude Code обычно не нужен: новые команды появятся сразу. Если не появились — перезапустите один раз.
