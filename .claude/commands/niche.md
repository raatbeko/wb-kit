Разбери нишу продавца на Wildberries. Аргументы: $ARGUMENTS

Если в аргументах «демо» или «demo» — `npm run niche -- --demo`, дальше сразу шаг 4 (папка `reports/niche-ГГГГ-ММ-ДД-demo`). Скажи, что данные выдуманные.

## 1. Какую нишу смотреть

- Запросы из аргументов — как есть (не больше 3 за раз: каждый — две страницы WB).
- Нет аргументов — ниша самого продавца: `npm run niche -- --mine`. Скрипт выдаст его предметы по выручке из последнего аудита (или из карточек по ключу) и запрос для каждого. Возьми 1–3 главных. Если хочется точнее — `get_search_texts` подскажет, как именно покупатели ищут его товары.
- Покажи запросы человеку одной строкой и продолжай.

## 2. Снять выдачу в браузере

Браузер, правила и прокрутка — как в `.claude/commands/competitors.md`, шаг 2. **Не вызывай внутренние API WB** (`/__internal/…`, `search.wb.ru`, `card.wb.ru`), капчу проходит человек.

Для каждого запроса две страницы:
1. «По популярности»: `https://www.wildberries.ru/catalog/0/search.aspx?search=<запрос>` — прокрутить до 100 карточек.
2. «Новинки»: та же ссылка с `&sort=newly` — хватит 60 карточек.

На каждой странице выполни код `competitors/extract-search.js` целиком и сохрани ответ в `reports/niche-ГГГГ-ММ-ДД/raw/<запрос>.json` и `<запрос>.new.json`. Ссылку страницы не меняй: по `sort=newly` скрипт понимает, что это новинки.

## 3. Собрать отчёт

`npm run niche -- --dir reports/niche-ГГГГ-ММ-ДД` (таймаут 10 минут: фото ищутся на CDN WB по одному). Свои артикулы скрипт возьмёт из аудита или по ключу; без них — `--own 123,456` или без своих.

**Продажи — только если подключён MPSTATS** (`mcp__mpstats__*`): по правилам `.claude/commands/competitors.md` («Продажи конкурентов») возьми продажи за 30 дней для первых 30 карточек и новинок из топа, запиши `mpstats.json` в папку отчёта и выполни `npm run niche -- --render <папка>`. Перед запросами скажи, сколько запросов MPSTATS потратишь. Нет MPSTATS — одной строкой скажи, что объёмы продаж видны только с ним.

## 4. Выводы

Прочитай `summary.json` и напиши `insights.md`:
- **Вердикт** по каждому запросу (`verdict`) своими словами: можно ли заходить и почему.
- **Сегменты** — где деньги: сегмент с высокой ценой и небольшим числом отзывов — кандидат.
- **Новинки в топе** — что у них общего (цена, сегмент), что из этого стоит попробовать.
- **Где продавец** (`own`) и что сделать, чтобы подняться.
- **Деньги со штуки** (`economy`) — только как оценку; нет себестоимости — так и скажи.

Только цифры из выжимки, без выдумок. Затем `npm run niche -- --render <папка>`.

## 5. Ответить

Коротко: вердикт, 2–3 главных наблюдения, что попробовать. Путь к HTML (там фото лидеров и новинок, всё кликается на WB) и Excel. Панель обновится сама, вкладка «Ниша».

## Раз в неделю сам

Если человек хочет, чтобы нишу проверяли регулярно, — предложи запланированную задачу Claude (в приложении Claude: «Запланированные задачи», раз в неделю, команда `/niche <запросы>`). Предупреди: она работает, только когда компьютер включён и Claude открыт; тратит лимиты подписки Claude, а с MPSTATS — и его лимиты. Ежедневная сводка (`npm run digest`) работает без Claude — это другое.
