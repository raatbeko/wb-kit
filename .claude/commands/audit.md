Сделай аудит кабинета продавца Wildberries. Аргументы: $ARGUMENTS

## 1. Собрать данные

- Если в аргументах есть «демо» или «demo», либо ключ WB не настроен (`npm run check -- --json` → `ok: false` из-за ключа), запусти демо: `npm run audit -- --demo`. Скажи человеку, что это выдуманный магазин для примера.
- Иначе: `npm run audit` (с `-- --days N`, если в аргументах число от 7 до 60).
- Раздел «По месяцам» по умолчанию — за 3 календарных месяца. Если человек просит другие месяцы («за полгода», «с начала года») — добавь `--months N` (до 12). Каждый месяц — ещё минута: финансы WB отдают 1 запрос в минуту.
- Перед запуском предупреди: с настоящим ключом сбор занимает 3–6 минут (с `--months 12` — до 15), WB отдаёт отчёты не чаще раза в минуту. Запускай команду с таймаутом 10 минут, а при `--months` больше 4 — в фоне.
- В выводе команды — путь к папке отчёта. Если какие-то разделы недоступны (нет категории в ключе) — это нормально, отчёт строится без них.

## 2. Написать выводы

Прочитай `summary.json` в папке отчёта (не `data.json` — он большой). По нему напиши файл `insights.md` в той же папке:

- **3–5 главных выводов** — коротко, с цифрами из выжимки. Первый вывод — про деньги из `economics`: прибыль и маржа (или, если `profit` равен null, сколько остаётся после WB и рекламы — и что это ещё не прибыль), сколько копеек с рубля забирают WB и реклама, окупается ли реклама (`drrBuyouts` против `breakEvenDrr`). Если в выжимке есть `months` — одной фразой сравни месяцы по прибыли в день (неполный месяц `partial` — только так, не по сумме). Дальше — где теряются деньги.
- **План на эту неделю** — 3–7 конкретных действий по порядку, начиная с того, что даёт больше денег или останавливает потери.
- **О чём жалуются покупатели** — сгруппируй `negativeFeedbacks` по причинам (размер, брак, цвет, доставка…) и товарам. 2–4 пункта.

Правила для выводов:
- Пиши для владельца магазина, не для аналитика: простые слова, без англицизмов, суммы в рублях.
- Только цифры из выжимки. Не выдумывай и не округляй до неузнаваемости.
- Прибыль называй прибылью, только если `economics.profit` не null. Если `costCoverage` меньше 100 — скажи, что прибыль завышена: не у всех товаров вписана себестоимость.
- ДРР — всегда от выкупов (`drrBuyouts`), не от заказов.
- Называя товар или кампанию, сверяй название и сумму в одной и той же строке выжимки (у рекламных кампаний название — в поле `title`). Перепутать, какая кампания дороже, — частая ошибка.
- Если раздел недоступен (`unavailable`) — одной строкой скажи, чего не хватает и как добавить категорию в ключ.
- Если это демо — так и напиши в начале.
- Формат: markdown, заголовки `###`, списки `-` и `1.`, жирный `**…**`. Без таблиц и ссылок.

## 3. Пересобрать отчёт с выводами

`npm run audit -- --render <папка отчёта>` — HTML и Excel пересоберутся, выводы окажутся в начале отчёта. Панель магазина (`reports/panel/Панель.html`, демо — `Панель ДЕМО.html`) пересобирается сама после каждой команды аудита; если человек держит её открытой, страница обновится.

Живой статус: перед сбором запиши `reports/panel/status.js` (формат — `.claude/commands/panel.md`) с `run` «Аудит магазина» и `step` «Собираю данные WB — это 3–6 минут», после выводов — с `done: true`.

## 4. Ответить человеку

В чате коротко: 3 главных вывода и что сделать первым. Если в отчёте есть задача `no_costs` — предложи вписать себестоимость: `npm run cost -- --init` создаст `data/cost.csv`, человек заполняет его в Excel или диктует цифры тебе в чат, потом `npm run audit -- --render <папка>` пересоберёт отчёт уже с прибылью. Дай путь к HTML-отчёту и Excel (их можно открыть двойным щелчком и переслать) и к панели: там те же цифры графиками, и всё нажимается. Предложи следующий шаг: например, подготовить ответы на отзывы без ответа или разобрать конкретный товар.

## Деньги по месяцам без полного аудита

Если человек спрашивает только «сколько я заработал в августе» или «по месяцам за год», полный аудит не нужен: вызови `get_finance_summary` по месяцу (по очереди, 1 запрос в минуту) и `get_ad_costs` за те же даты, а себестоимость возьми из `data/cost.csv`. Покажи таблицу «Месяц | Выручка | На руки | Реклама | Себестоимость и налог | Прибыль». Без себестоимости последняя колонка — «после WB и рекламы». Предупреди, что финотчёт за последнюю неделю может ещё не прийти.

Ничего не меняй в кабинете во время аудита.
