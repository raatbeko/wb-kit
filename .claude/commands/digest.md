Утренняя сводка по магазину. Аргументы: $ARGUMENTS

Сводка — обычный скрипт без Claude: заказы вчера, что закончилось и скоро закончится, что просело, отзывы без ответа, расход на рекламу и 1–3 дела на сегодня. Подписку Claude она не тратит.

## Что сделать по аргументам

- Пусто — собрать сейчас: `npm run digest` (1–2 минуты, лимиты WB). Покажи итог из вывода и предложи включить расписание, если его нет.
- «демо» — `npm run digest -- --demo --no-send`, покажи панель `reports/panel/Панель ДЕМО.html`.
- «расписание 08:00», «каждое утро» — `npm run digest -- --schedule 08:00` (время — какое скажет человек, по умолчанию 08:00). Задача появится в Планировщике заданий Windows; если компьютер в это время выключен — сводка соберётся при включении. Не больше одной в день.
- «выключить» — `npm run digest -- --unschedule`.
- «telegram» — подключить Telegram:
  1. Нет токена бота — объясни: в Telegram открыть @BotFather, `/newbot`, придумать имя, прислать токен сюда или вписать в `.env` самому. Присланный токен сохрани: `npm run set-key -- TELEGRAM_BOT_TOKEN <токен>`. Никогда не повторяй его в ответе.
  2. Попроси открыть своего бота и нажать «Start».
  3. `npm run telegram` — найдёт чат, запишет `TELEGRAM_CHAT_ID`, пришлёт тестовое сообщение. ID чата у человека не спрашивай.

## Если что-то не так

- В сводке «нет доступа» — каких категорий не хватает в ключе WB, скажет `npm run check`.
- Сводка не пришла утром — посмотри последние строки `reports/digest/log.txt` и перескажи.
- Сводке в панели больше двух дней — расписание не работает или компьютер не включали; проверь `--schedule` ещё раз.
