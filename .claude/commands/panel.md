Открой человеку панель магазина. Аргументы: $ARGUMENTS

## 1. Собрать и открыть

- В аргументах «демо» или «demo», либо ключ WB не настроен: если в `reports/` нет папки `audit-…-demo`, сначала `npm run audit -- --demo`. Потом `npm run panel -- --demo`.
- Иначе: `npm run panel`. Если аудита ещё нет, панель всё равно откроется и подскажет начать с `/audit` — предложи его.

Команда сама откроет страницу в браузере. Если не открылась — дай путь из вывода: `reports/panel/Панель.html` (демо — `Панель ДЕМО.html`), её открывают двойным щелчком.

## 2. Объяснить в двух строках

- Вкладки: «Обзор» — цифры, графики, сотрудники и что сделать первым; «Аудит», «Офис», «Конкуренты», «Карточки» — последние отчёты целиком.
- Всё нажимается: плитка, сотрудник, строка консоли, товар — справа откроются подробности. Кнопка «Спросить Claude» копирует готовый вопрос — его вставляют в этот чат.
- Пока Claude работает (`/audit`, `/office`…), вверху панели видно, кто чем занят. Когда отчёт готов, страница обновится сама. Держать её открытой можно всё время.

## Живой статус — `reports/panel/status.js`

Панель каждые 3 секунды читает этот файл. Пиши его инструментом Write целиком (это разрешено без вопросов), а не командой. Формат — строго такой:

```js
window.WB_STATUS = {
  "run": "Разбор недели",
  "step": "Логист смотрит остатки",
  "pct": 40,
  "done": false,
  "agents": { "аналитик": "done", "логист": "run", "маркетолог": "wait" },
  "log": [
    ["аналитик", "bad", "Тапочки продаются в минус: −379 ₽ с пары"],
    ["логист", "warn", "Плед закончится через 3 дня"]
  ]
};
```

- `run` — что делаем, словами человека; `step` — текущий шаг одной строкой.
- `pct` — процент, только если он честный (сделано 2 шага из 5 → 40). Не знаешь — не пиши поле: полоса будет «бегущей».
- `agents` — роли: `аналитик`, `логист`, `отзывы`, `маркетолог`, `разведчик`, `контент`; состояние `run`, `done` или `wait`. Роли, которых нет в списке, панель покажет как «не участвует».
- `log` — находки для консоли: `[роль или "Claude", "bad" | "warn" | "ok", "текст"]`. Только цифры из отчётов и ответов ролей, 1–3 главные находки на роль. Новые строки добавляй в конец, старые не убирай.
- `done: true` — работа закончена: баннер покажет «Готово» и спрячется. В `step` в этот момент — итог одной фразой.

Когда писать: в начале работы, после каждого заметного шага (роли ответили, директор сводит план) и в конце с `done: true`. Не чаще, чем раз в шаг: это не лог, а табло. Поле `built` не трогай — его ставит сборка панели. Если файл не получилось записать — работай дальше: панель без статуса просто показывает последние отчёты.
