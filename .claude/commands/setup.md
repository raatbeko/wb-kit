---
description: Настроить wb-kit — установить зависимости, подключить ключ WB, проверить доступ
---

Ты помогаешь продавцу Wildberries настроить wb-kit. Человек может быть не программистом. Говори просто, по-русски, по одному шагу за раз, без жаргона. В конце настройки у человека должен быть настоящий отчёт по его магазину, а не просто слово «готово».

## Шаги

1. **Зависимости.** Если в корне нет папки `node_modules`, выполни `npm install`.
   - Если команда `npm` не найдена: объясни, что нужно установить Node.js 22 LTS с nodejs.org, после установки полностью закрыть и снова открыть Claude Code (иначе он не увидит Node), и остановись.
   - На Windows, если ошибка про `bash` или Git: нужен Git for Windows (git-scm.com, установка по умолчанию), потом перезапуск Claude Code.

2. **Проверка.** Выполни `npm run check -- --json` и перескажи результат человеческими словами. Сырой JSON не показывай.

3. **Если ключа WB нет или он не работает** — объясни, как его получить:
   - Открыть кабинет продавца WB → «Настройки» → «Доступ к API».
   - Нажать «Создать новый токен», тип — «Персональный» (или «Базовый»).
   - Отметить **все категории** и галочку «Только на чтение». Для анализа этого достаточно, и так безопаснее.
   - Скопировать ключ (длинная строка из трёх частей через точки).
   - Открыть файл `.env` в папке wb-kit, вставить ключ после `WB_API_TOKEN=` (без пробелов и кавычек) и сохранить.

   Попроси вставлять ключ **в файл `.env`, а не в чат**. Если человек всё-таки прислал ключ в чат — сохрани его командой `npm run set-key -- WB_API_TOKEN <ключ>` (она меняет одну строку и не показывает остальные ключи) и мягко скажи, что в следующий раз лучше сразу в файл. Никогда не повторяй ключ в ответах.

   Пока ключа нет, предложи посмотреть пример: `/audit демо` — тот же отчёт на выдуманном магазине. Человек сразу поймёт, что получит.

4. **После вписывания ключа** снова выполни `npm run check -- --json`.
   - Если каких-то категорий нет — перечисли, что из-за этого не будет работать (поле `features`), и предложи пересоздать ключ со всеми категориями. Работу это не блокирует: продолжаем с тем, что есть.
   - Если WB недоступен (нет связи) — подскажи проверить интернет и VPN.
   - Если ключ скоро истечёт (меньше 14 дней) — скажи дату и напомни создать новый заранее.

5. **Перезапуск инструментов.** MCP-сервер `wb` читает ключ при запуске. Попроси перезапустить Claude Code: в приложении — закрыть и открыть сессию заново, в терминальной версии — `/mcp` → `wb` → Reconnect. Заранее предупреди: Claude Code может спросить, разрешить ли сервер `wb` из этой папки, — нужно ответить «да». Без этого Claude не увидит кабинет.

   После перезапуска вызови `check_connection`.
   - Если инструментов `wb` не видно совсем, почти всегда причина одна: Claude Code не доверяет папке. Тогда настройки набора не действуют. Попроси открыть папку wb-kit заново и на вопрос «Доверяете ли вы этой папке?» ответить «да».
   - Если доверие есть, а инструментов всё равно нет — `npm run check` и `/mcp` покажут статус `wb`.

6. **Пробный запрос — доказательство, что всё работает.** Вызови `get_seller_info` и `list_products` (только первая страница). Покажи одной строкой: название магазина и сколько карточек нашлось. Например: «Вижу магазин „Уютный дом“, 48 карточек — подключение работает». Если вызов упал — объясни ошибку словами и вернись к шагу 4.

7. **Себестоимость — чтобы считать настоящую прибыль.** WB не знает, сколько товар стоит продавцу. Без этого отчёт покажет выручку и удержания WB, но не прибыль. Предложи (не обязательно, можно позже):
   - Выполни `npm run cost -- --init`. Команда создаст `data/cost.csv` со всеми артикулами магазина и пустой колонкой себестоимости. Если файл уже есть, она только допишет новые артикулы.
   - Человек открывает файл в Excel и вписывает себестоимость одной штуки в рублях: закупка, упаковка, доставка до склада WB. Колонку налога, если он есть, — в процентах от выручки (например, 6 для УСН «доходы»).
   - Если человек готов продиктовать цифры прямо в чате — впиши их в `data/cost.csv` сам. Если без себестоимости — ничего страшного: аудит пометит, где её не хватает.

8. **Стиль ответов на отзывы.** Если файла `data/brand.md` нет, задай 3 коротких вопроса (можно одним сообщением):
   - как обращаться к покупателям: на «вы» или на «ты»;
   - подпись в конце ответа (например, «Команда Уютного дома») или без подписи;
   - что можно обещать недовольному покупателю: замену, возврат, промокод — или ничего не обещать.

   По ответам создай `data/brand.md` — 5–8 строк своими словами. Менеджер отзывов будет следовать этому стилю. Если человек хочет пропустить — пропусти, стиль по умолчанию: вежливо на «вы», без подписи.

9. **Браузер для `/competitors`.** Посмотри, есть ли у тебя инструменты браузера: расширение Claude для Chrome (`mcp__claude-in-chrome__*`) или встроенный браузер приложения (`mcp__Claude_Browser__*`).
   - Есть — скажи, что `/competitors` будет работать.
   - Нет — объясни, что для конкурентов нужен браузер: в приложении Claude он встроенный (вкладка Code), в терминальной версии — расширение «Claude in Chrome» из магазина Chrome. Остальной набор работает и без него.

10. **Необязательно — MPSTATS.** Посмотри, есть ли среди твоих инструментов MCP-сервер MPSTATS (`mcp__mpstats__*`).
    - Есть — скажи, что он подключён: в отчёте о конкурентах появятся их продажи, а в `/card` — генерация инфографики. Это тратит лимиты подписки, поэтому Claude каждый раз спрашивает.
    - Нет — спроси, есть ли подписка MPSTATS. Если есть: MPSTATS подключается отдельным MCP-сервером по инструкции MPSTATS (имя сервера лучше дать `mpstats`), его токен вписывается в настройки этого сервера, а не в `.env`. После подключения нужен перезапуск Claude Code.
    - Подписки нет — скажи, что конкурентов будем смотреть через браузер, это бесплатно.

11. **Первый отчёт.** Коротко перечисли, что заработало (таблица «Что | Работает?»). Затем предложи сразу запустить `/audit`: полный отчёт по магазину с планом действий. Предупреди, что он займёт 3–6 минут. Если человек согласен — выполни шаги команды `/audit` (файл `.claude/commands/audit.md`). Одной строкой упомяни, что дальше есть:
    - `/competitors` — конкуренты в поиске;
    - `/card` — текст карточки под запросы покупателей;
    - `/office` — разбор магазина командой ролей.

## Правила

- Ничего не меняй в кабинете WB во время настройки.
- Не открывай и не выводи `.env`: там ключи.
- Если что-то сломалось и непонятно почему — выполни `npm run check` (без `--json`) и покажи человеку вывод: там есть подсказки, как исправить.
- Шаги 7–10 необязательные. Если человек торопится, сделай шаги 1–6 и 11, а про остальное скажи одной строкой, что их можно сделать позже той же командой `/setup`.
