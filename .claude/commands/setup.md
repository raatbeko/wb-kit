description: Настроить wb-kit — установить зависимости, подключить ключ WB, проверить доступ
---

Ты помогаешь продавцу Wildberries настроить wb-kit. Человек может быть не программистом: говори просто, по-русски, по одному шагу за раз, без жаргона.

## Шаги

1. **Зависимости.** Если в корне нет папки `node_modules`, выполни `npm install`. Если команда `npm` не найдена — объясни, что нужно установить Node.js 22 LTS с nodejs.org, и остановись.

2. **Проверка.** Выполни `npm run check -- --json` и разбери результат. Не показывай сырой JSON — перескажи человеческими словами.

3. **Если ключа WB нет или он не работает** — объясни, как его получить:
   - Открыть кабинет продавца WB → «Настройки» → «Доступ к API».
   - Нажать «Создать новый токен», тип — «Персональный» (или «Базовый»).
   - Отметить **все категории** и галочку «Только на чтение» — для анализа этого достаточно, и так безопаснее.
   - Скопировать ключ (длинная строка из трёх частей через точки).
   - Открыть файл `.env` в папке wb-kit и вставить ключ после `WB_API_TOKEN=` (без пробелов и кавычек), сохранить.

   Попроси вставлять ключ **в файл `.env`, а не в чат**. Если человек всё-таки прислал ключ в чат — сохрани его командой `npm run set-key -- WB_API_TOKEN <ключ>` (она меняет одну строку и не показывает остальные ключи) и мягко скажи, что в следующий раз лучше сразу в файл. Так же сохраняется `MPSTATS_TOKEN`. Никогда не повторяй ключ в ответах.

4. **После вписывания ключа** снова выполни `npm run check -- --json`.
   - Если каких-то категорий нет — перечисли, что из-за этого не будет работать (поле `features`), и предложи пересоздать ключ со всеми категориями. Это не блокирует работу: продолжаем с тем, что есть.
   - Если WB недоступен (нет связи) — подскажи проверить интернет и VPN.

5. **Перезапуск инструментов.** MCP-сервер `wb` читает ключ при запуске. Попроси человека перезапустить Claude Code (или в терминальной версии: `/mcp` → `wb` → Reconnect). Если Claude Code спросит, разрешить ли сервер `wb` из этой папки, — нужно ответить «да». После этого вызови инструмент `check_connection`, чтобы убедиться, что инструменты видят ключ. Если инструментов `wb` не видно совсем — сервер не одобрен или не запустился: попроси открыть `/mcp` и посмотреть статус `wb`.

6. **Необязательно — MPSTATS.** Спроси, есть ли подписка MPSTATS. Если да — токен вписывается в `.env` после `MPSTATS_TOKEN=` (mpstats.io/userpanel → API token). С MPSTATS в отчёте о конкурентах появятся их продажи, а в `/card` — генерация инфографики (тратит лимиты подписки, Claude каждый раз спрашивает). После вписывания снова `npm run check -- --json`: если jq или dwebp не установлены, подскажи команду из поля `fix`. Если подписки нет — скажи, что конкурентов будем смотреть через браузер, это бесплатно.

7. **Готово.** Кратко скажи, что заработало, и предложи первый шаг — команду `/audit`: полный отчёт по магазину с планом действий. Если категорий в ключе не хватает, отчёт всё равно построится, просто без части разделов. Одной строкой упомяни, что дальше есть `/competitors` (конкуренты в поиске) и `/card` (текст карточки под запросы покупателей).

## Правила

- Ничего не меняй в кабинете WB во время настройки.
- Не открывай и не выводи содержимое `.env` целиком: там ключи.
- Если что-то сломалось и непонятно почему — выполни `npm run check` (без `--json`) и покажи человеку вывод: там есть подсказки, как исправить.
