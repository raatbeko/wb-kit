Сравни товары продавца с конкурентами в поиске Wildberries. Аргументы: $ARGUMENTS

Если в аргументах «демо» или «demo» — выполни `npm run competitors -- --demo` и переходи сразу к шагу 4 (папка `reports/competitors-ГГГГ-ММ-ДД-demo`). Скажи, что это выдуманные данные.

## 1. Выбрать запросы

- Запросы из аргументов — как есть (не больше 5 за раз).
- Если аргументов нет: возьми 3 главных товара из последнего аудита (`reports/audit-*/summary.json`, поле `topProducts`) и для каждого найди главный поисковый запрос инструментом `get_search_texts` (первый по заказам). Если аудита или ключа нет — предложи 2–3 запроса по названиям товаров и спроси человека, подходят ли.
- Покажи список запросов человеку одной строкой и продолжай.

## 2. Снять выдачу в браузере

Браузер: Claude in Chrome (инструменты `mcp__claude-in-chrome__*`), если подключён; иначе встроенный браузер (`mcp__Claude_Browser__*`). Скажи человеку, что откроется вкладка WB.

Для каждого запроса:
1. Открой `https://www.wildberries.ru/catalog/0/search.aspx?search=<запрос, закодированный для URL>`.
2. Прокручивай страницу вниз (через JavaScript: `window.scrollTo(0, document.body.scrollHeight)` с паузой ~0,7 с), пока карточек `article[data-nm-id]` не станет 100. Если число перестало расти — прокрути на экран вверх и снова вниз: WB подгружает следующую порцию, когда видит движение. Если и так не растёт три раза подряд — бери, что есть.
3. Прочитай файл `competitors/extract-search.js` и выполни его код на странице целиком, как есть. Он вернёт объект `{ query, url, scannedAt, cards }`.
4. Сохрани результат как JSON в `reports/competitors-ГГГГ-ММ-ДД/raw/<запрос-латиницей-или-через-дефисы>.json`.
5. Между запросами — пауза в несколько секунд.

Правила:
- Читай только то, что показано на странице. **Не вызывай внутренние API WB** (`/__internal/…`, `search.wb.ru`, `card.wb.ru`) — ни через fetch, ни иначе.
- Не входи в аккаунт, не нажимай на рекламу, не добавляй в корзину.
- Если WB показал проверку «я не робот» или капчу — остановись, попроси человека пройти её в браузере самому и после этого продолжи. Не пытайся обойти проверку.
- В конце закрой вкладку, которую открыл.

## 3. Собрать отчёт

`npm run competitors -- --dir reports/competitors-ГГГГ-ММ-ДД` (таймаут 10 минут: описания карточек загружаются по одной, с паузами).

- Свои товары скрипт найдёт сам по ключу WB. Без ключа спроси у человека артикулы WB его товаров и добавь `--own 123,456`. Если человек не знает — можно без них: отчёт покажет рынок.
- Скрипт сам сравнит с прошлой проверкой этих же запросов, если она была.

### Продажи конкурентов (только если подключён MPSTATS)

Если среди твоих инструментов есть MCP-сервер MPSTATS (`mcp__mpstats__*`), добавь продажи. Иначе пропусти этот шаг и в выводах одной строкой скажи, что продажи конкурентов видны только с подпиской MPSTATS.

1. Если у сервера есть инструмент остатка лимитов — проверь, сколько запросов осталось. Нужно примерно 1 запрос на артикул; если остаток меньше — бери только первую пятёрку и свои товары. Перед запросами одной строкой скажи человеку, сколько запросов MPSTATS потратишь.
2. Для первой десятки каждого запроса и для своих товаров из `summary.json` возьми продажи артикула WB за последние 30 дней (конец — вчера).
3. Из ответа возьми продажи в штуках и выручку в рублях за период. Названия полей смотри в самом ответе; если сомневаешься, что поле значит, — не подставляй, пропусти артикул. Проверяй здравый смысл: выручка ≈ цена × штуки.
4. Запиши `mpstats.json` в папку отчёта строго в таком виде:
   ```json
   { "source": "MPSTATS", "period": { "from": "ГГГГ-ММ-ДД", "to": "ГГГГ-ММ-ДД" },
     "items": [ { "nmId": 123456789, "sales": 456, "revenue": 789000 } ] }
   ```
5. `npm run competitors -- --render <папка отчёта>` — продажи появятся в таблицах, в Excel и в `summary.json`.

## 4. Написать выводы

Прочитай `summary.json` в папке отчёта и напиши `insights.md` там же:

- **По каждому запросу** — 1–2 предложения: где товары продавца относительно рынка (место, цена против медианы лидеров, отзывы, рейтинг).
- **Что сделать** — 3–6 конкретных действий по порядку пользы: цена, фото и видео, описание и характеристики, отзывы, участие в акциях, реклама по запросу.
- **Что изменилось с прошлого раза** — если в `changes` есть данные.
- **Продажи** — если есть `salesSource`: сколько продают лидеры и товары продавца, кто зарабатывает больше всех и почему (цена, отзывы, место).

Правила те же, что для аудита: простые слова, только цифры из выжимки, название и сумму сверяй по одной строке. Если это демо — скажи об этом в начале. Формат: markdown, заголовки `###`, списки, жирный.

Затем `npm run competitors -- --render <папка отчёта>`.

## 5. Ответить человеку

Коротко в чате: главное по каждому запросу и что сделать первым. Дай пути к HTML-отчёту и Excel. Напомни, что позиции в поиске зависят от региона и истории покупателя, поэтому у других людей могут немного отличаться, и что повторный запуск через неделю покажет, что изменилось.
