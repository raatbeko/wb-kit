# Дополнение «Панель» — как добавить в установленный wb-kit

Это инструкция для Claude, который работает в папке wb-kit у продавца. Человек дал тебе архив ветки `panel` и просит добавить панель. Делай по шагам и рассказывай простыми словами, что происходит.

## Что даёт дополнение

- Команда `/panel` — одна страница в браузере вместо пачки отчётов: цифры, графики, сотрудники, план и все отчёты вкладками. Всё нажимается, у каждой детали — кнопка «Спросить Claude».
- Пока ты работаешь (`/audit`, `/office`), человек видит в панели, кто из сотрудников чем занят. Это файл `reports/panel/status.js`, его пишешь ты.
- Аудит, офис, конкуренты и карточки сами пересобирают панель — открытая страница обновляется.

Новых зависимостей нет: `npm install` не нужен.

## 1. Проверить, что папку можно дополнять

Архив — вся ветка `panel`: это основная версия wb-kit от 21.11.2026 (последнее изменение — «Аудит: сколько заработано по месяцам») плюс панель.

- Если в папке человека есть `.git` — выполни `git log --oneline -1`. Коммит `985ff3c` — можно просто заменить файлы (шаг 2).
- Если git нет или коммит другой — сравни файлы из списка «Изменены» ниже с архивом. Если отличаются только строки панели — заменяй. Если человек или кто-то ещё правил эти файлы сам — не затирай: перенеси изменения из архива вручную (они небольшие, описаны ниже).

## 2. Скопировать файлы

Распакуй архив во временную папку (не в папку wb-kit) и скопируй оттуда.

**Новые — скопировать как есть:**

- `panel/build.ts`, `panel/panel.test.ts` — сама панель и её тесты
- `scripts/panel.ts` — команда `npm run panel`
- `.claude/commands/panel.md` — команда `/panel` и формат живого статуса
- `docs/demo-panel.html` — пример панели на выдуманном магазине
- `ДОПОЛНЕНИЕ-ПАНЕЛЬ.md` — эта инструкция

**Изменены — заменить или перенести правки:**

| Файл | Что добавлено |
|---|---|
| `package.json` | скрипт `"panel": "tsx scripts/panel.ts"` |
| `tsconfig.json`, `vitest.config.ts` | папка `panel/` в проверку типов и тесты |
| `scripts/audit.ts`, `scripts/office.ts`, `scripts/competitors.ts`, `scripts/card.ts` | импорт `refreshPanel` и один вызов в конце сборки отчёта |
| `.claude/commands/audit.md`, `office.md`, `wb.md` | живой статус, ссылка на панель, строка `/panel` в меню |
| `CLAUDE.md`, `README.md` | описание `/panel` |

**Не трогать:** `.env`, `data/` (себестоимость, стиль бренда), `reports/` — это данные человека, в архиве их нет.

## 3. Разрешить команду без лишних вопросов

В `.claude/settings.json`, в список `permissions.allow`, добавь строку рядом с другими `npm run`:

```json
"Bash(npm run panel:*)",
```

Покажи человеку эту правку и спроси разрешения: файл настроек меняет то, о чём Claude Code спрашивает. Если человек против — ничего страшного, Claude Code просто будет спрашивать перед `npm run panel`.

## 4. Проверить

1. `npm test` — все тесты должны пройти.
2. `npm run audit -- --demo`, потом `npm run panel -- --demo` — откроется панель выдуманного магазина «Уютный дом».
3. Если ключ WB настроен — `npm run panel`: панель по последним настоящим отчётам. Аудита ещё нет — предложи `/audit`.

## 5. Рассказать человеку

Коротко: «Теперь есть `/panel` — страница со всеми цифрами и отчётами, всё нажимается. Пока я работаю, там видно, кто из сотрудников чем занят. Попробуйте: `/panel демо`». Перезапускать Claude Code не нужно — новая команда `/panel` появится сразу (если нет — перезапустите один раз).
